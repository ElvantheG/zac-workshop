## Section Templates (Verbatim Patterns to Copy)

### 1. Header + Nav
- **Title:** "[Method Name] — Resource Hub"
- **Nav links:** Start Here · Prompts · Skills · Reference · FAQ · [Paid Offer Name]
- **Persistent CTA top-right:** "[Paid Offer] →"

### 2. Hero
- **Headline pattern:** "Everything From the Workshop. In One Place."
- **Subhead pattern:** "[Specific deliverables list] and [outcome promise]."
- **3 large cards:** Master Asset · Walkthrough · Paid Offer

### 3. Four-Part Walkthrough
- Each phase has:
  - Step name
  - Time estimate ("10 minutes," "2 hours")
  - Specific commands/triggers
  - Embedded micro-CTAs

### 4. Mega Prompt / Master Asset
- Large code block / copy-paste content
- Visible **Copy** button
- Instruction: where to paste, what to expect

### 5. Sub-Prompts (3 variants)
- Each with:
  - Use case description ("When to use")
  - Workflow phases
  - Copy button
  - Tech stack notes

### 6. Skills / Tools Stack
- Numbered list of 5–7 personal recommendations
- Star counts / credibility indicators
- Brief one-line description per item
- Install commands inline
- Framing: "Install nothing else"

### 7. Pipeline Diagram
- Visual: 4–5 steps from raw → polished
- One-line per step
- Install command at end

### 8. Comparison Cards
- 3 side-by-side options
- Best use case per option
- "Build this →" CTA per card

### 9. Tech Stack Reference
- Stack diagram
- Cost-optimization tricks
- Connector list (APIs, integrations)

### 10. FAQ
- 8–12 real questions
- Detailed answers (not one-liners)
- Cover: model choice, security, cost, debugging, "will this work for me?"

### 11. Manifesto
- 5–8 numbered principles
- Each is a punchy declaration ("Sell first. Build second.")
- Establishes philosophy

### 12. Case Study (CRITICAL — comes BEFORE the upsell)
- Before/after numbers
- Revenue progression
- Screenshots if possible
- Link to live example
- **Position:** Right before the ask. Primes belief.

### 13. Paid Upsell — The Ask
**Headline pattern:** "Build the offer. Build the tools. Together. Live."
**Body must contain:**
- Program length + spots ("90 days, 5 spots")
- Outcome promise ("$7K/month minimum profit")
- Time commitment ("1 hour/day")
- **Two pricing tiers:**
  - Standard price (anchor)
  - Workshop attendee discount (perceived value)
- Deadline (specific date)
- **Personal CTA:** "DM me directly" (NOT a generic form)
- **Reframe:** "You're not buying training. You're a beta partner."

### 14. Workshop Replay / Bonus
- Video link
- Date + location (Skool, Discord, etc.)
- "Watch the Replay →" CTA

### 15. Footer
- Slides link
- Bonus tools
- Copyright/legal

## The Persuasion Bridge: Free → Paid

### The 3-Move Pattern
1. **Free resources ladder** (Sections 2–11): Progressively remove friction, build confidence
2. **Confidence checkpoint** (Section 12 — Case Study): Revenue proof primes belief BEFORE ask
3. **The Ask** (Section 13): Specific price + scarcity + personal CTA + beta-partner reframe

### Pricing Architecture
- **Standard price** as anchor ("$250 down + $250/week")
- **Discount tier** as reward ("$50 first week for workshop attendees")
- The discount makes the offer feel like a gift, not a transaction

### Urgency + Exclusivity Combo
- "5 spots open" (scarcity)
- "Deadline: [specific date]" (urgency)
- "DM me directly" (exclusivity / personal access)
- These three together override price objection

### Objection Preemption (FAQ does this)
- "Is this legit?" → Case study + live examples + workshop replay
- "Will this work for me?" → 3 path options
- "Too technical?" → "You don't need to code"
- "Too expensive?" → Cost-engineering shown ("$6/month per 50 clients")
- "I don't have content yet?" → Master asset handles setup

### Headline Progression (Down the Page)
1. "Everything in One Place" — completeness
2. "The [Master Asset Name]" — single-thing focus
3. "The 3 [Sub-Templates]" — choice
4. "Build [outcome]. Together. Live." — DIY-to-guided shift
5. "5 Spots Open" — scarcity + status
