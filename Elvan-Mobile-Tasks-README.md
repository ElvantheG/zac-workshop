# 📱 Elvan — Mobile Tasks

Et enkelt sted at gemme alt det jeg laver, noterer og opdager fra mobilen.

---

## Hvad gemmes her

| Mappe | Indhold |
|-------|---------|
| `noter/` | Hurtige tanker, indsigter, ideer |
| `klienter/` | Noter fra sessioner, opfølgning |
| `hd-research/` | Human Design og Gene Keys opdagelser |
| `workshop/` | Indhold og ideer til workshops |
| `personligt/` | Refleksioner og energi-journaling |

---

## Sådan bruger jeg det

1. Åbn GitHub på mobilen
2. Naviger til den relevante mappe
3. Opret en ny fil → skriv dato som filnavn (fx `2026-05-10-indsigt.md`)
4. Gem og commit direkte

---

## Princip

> Ingen perfektion. Bare fang det mens det er friskt.

Alt her er arbejdsmateriale — ikke færdige produkter. Det handler om at bevare energien i en observation, så den ikke forsvinder.
